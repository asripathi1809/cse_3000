# Security Overview

## Intended Users

The intended users of this repository are:
-The course instructor
-The student (me) contributing to the project
-Class peers (if the repository is public or shared)

The code and data in this repository are intended strictly for academic and instructional purposes as part of coursework.

---

## Risk Assessment of Security Threats
This repository does not contain sensitive personal information, proprietary business data, or confidential credentials. 

Some potential risks may include:
- **Exposure to API keys or credentials** if they were accidentally committed
- **Plagiarism or misuse of academic work**

If the code were misused, it could result in things such as:
- Academic integrity issues
- Disruption of functionality

- Overall security risk level right now is **LOW**

## Security Measures Implemented

The following steps have been taken to secure this repository:
-The repository is set to **private** (if applicable).
-Only authorized collaborators have access.

## Future Security Considerations

If the project expands to include:
-User data
-External APIs
-Authentication systems

Then additional security measures would be implemented.
